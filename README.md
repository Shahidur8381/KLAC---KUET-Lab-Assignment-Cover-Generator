## ✨ Features

- 📝 **Dual Modes**: Generate both **Assignment Cover Pages** and **Lab Report Covers** seamlessly.
- ⚡ **Real-time Preview**: See your cover page format dynamically as you type.
- 📅 **Smart Date Math**: Automatically offsets submission and performance dates correctly matching the Bangladesh timezone (GMT+6).
- 📄 **1-Click PDF Export**: Clean, borderless, perfectly sized A4 PDF generation using html2pdf.js.
- 🎨 **KUET Standard Formatting**: Matches professional university guidelines perfectly.
- 📏 **Smart Text Wrapping**: Automatically handles exceptionally long names without breaking the layout.

## 🚀 Quick Start

1. **Clone or Download** this repository.
2. Ensure you have KUET.png and index.html in the same directory.
3. Open index.html in your favorite modern browser.
4. Fill in the required details on the left panel.
5. Click **Download Assignment/Lab Cover PDF** and you're done!

## 🛠 Tech Stack

- **Vanilla Web Technologies:** No heavy frameworks—just pure, optimized HTML, CSS (Flexbox & CSS Grid), and Javascript.
- **html2pdf.js** (via CDN) for robust document rendering.
