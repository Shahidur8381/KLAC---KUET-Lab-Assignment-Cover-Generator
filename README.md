# KUET Assignment Cover Page Generator

A simple browser-based tool for generating KUET assignment cover pages and downloading them as PDF.

## What it does

- Fills assignment cover details from a form
- Previews the formatted cover page live
- Exports the cover page as a PDF
- Works as a lightweight single-page HTML project

## Files

- `index.html` - the full app UI, styles, and PDF generation logic
- `KUET.png` - KUET logo used in the cover page

## How to use

1. Open `index.html` in a browser.
2. Enter the assignment, teacher, and student details.
3. Check the preview on the right.
4. Click **Download as PDF**.

## Notes

- The PDF export uses the `html2pdf.js` library from a CDN.
- Keep `KUET.png` in the same folder as `index.html` so the logo loads correctly.
